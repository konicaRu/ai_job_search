# AI Job Search RU

**Точная вакансия. Реальный опыт. Короткое письмо по делу.**

[Основа проекта](https://github.com/ai-job-search-dev/ai-job-search) · [Наш репозиторий](https://github.com/konicaRu/ai_job_search) · [План](AI_JOB_SEARCH_RU_PLAN_FINAL.md) · [Рабочий сценарий](AI_JOB_SEARCH_RU_SKILL_FINAL.md)

```text
Вакансия + твой опыт
        ↓
Проверка текста → исследование компании
        ↓
Черновик → проверка фактов и содержания → короткое письмо
        ↓
Переписка с HR → подготовка к интервью → разбор обратной связи
```

## Как начать

Открой проект в агенте и пришли ссылку или полный текст вакансии, резюме и описание выполненных задач. Агент читает `AGENTS.md` и русский рабочий сценарий, затем применяет оригинальные материалы `job-application-assistant`. Если опыта недостаточно, сначала уточняет факты.

Результат первого этапа — текст для ручной отправки. Поиск вакансий, новый CV и PDF не обязательны. Черновик и отправленное письмо учитываются отдельно.

## Что используется из исходника

| Компонент | Для чего |
|---|---|
| `.claude/skills/job-application-assistant/` | Профиль, стиль, персонализация, проверяемое исследование |
| `.claude/commands/apply.md` | Проверка фактов и цикл критики письма |
| `tools/posting_guard.py` | Проверка входного текста вакансии |
| `tools/fetch_page.py`, `tools/robots_check.py` | Резервная загрузка страниц с соблюдением robots.txt |
| `.claude/commands/interview.md` | Подготовка по этапам на основе конкретного отклика |

Python-инструменты извлекают и проверяют данные. Исследование и письмо выполняет агент с веб-поиском; отдельного LLM-сервера здесь нет.

## Проверка инструментов в PowerShell

Локально установлен Python 3.12.14. Из корня проекта:

```powershell
& '.runtime/python/cpython-3.12.14-windows-x86_64-none/python.exe' -m unittest tests.test_posting_guard tests.test_fetch_page tests.test_robots_check tests.test_page_decode
```

Результат проверки 2026-11-06: **149 тестов, OK**. Это проверка выбранных оригинальных утилит, а не всех функций проекта и не качества ещё не написанного письма.
