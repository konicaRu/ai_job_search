# MEMORY — журнал проекта

## Статус проекта

Подключён исходный ai-job-search, настроен первый сценарий: пользователь присылает вакансию и свой опыт → исследование компании → короткое русское сопроводительное → проверка и доработка. Автоматическая отправка не включена.

## Следующий шаг

Текущая работа: подготовка к финальному интервью по реальным материалам пользователя. Продолжение и подробные источники описаны в локальном `documents/interview/session_handoff_2026-11-09.md` (исключён из Git). Сначала прочитать его и указанный там файл подготовки; не начинать проект или настройку заново.

- CodeGraph не инициализирован; перед инициализацией спросить пользователя.
- Перед загрузкой персональных данных проверить приватность GitHub-репозитория.
- Bun, зависимости поисковых порталов и LaTeX отложены.
